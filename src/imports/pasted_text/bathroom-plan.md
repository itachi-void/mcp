# خطة التنفيذ الكاملة: الحمام الفاخر بطابع Greige (Luxury Greige Bathroom)

تهدف هذه الخطة إلى توثيق **آخر إصدار** من مشهد الحمام الفاخر بطابع الـ greige الدافئ والإكسسوارات الأسود المطفي (Matte Black)، بحيث يطابق الصورة المرجعية `src/imports/ref_bathroom.jpg`، ويبقى متوافقاً مع مشهدي المطبخ `Kitchen_Scene` وغرفة النوم `Bedroom_Scene` داخل نفس منظومة العرض التفاعلي في `src/App.tsx`.

المشهد مبني في React Three Fiber داخل `src/components/bathroom/BathroomScene.tsx`، ويُصدَّر بسكربت Blender مُطابق في `public/bathroom_blender.py` (قابل للتنزيل من تبويب الكود في التطبيق عبر `/bathroom_blender.py`).

اصطلاح المحاور: `x = يسار(-)/يمين(+)`، `y = أعلى`، `z = خلف(-)/أمام-الكاميرا(+)`. أبعاد القشرة: `W=6.6m`، `D=6.0m`، `H=2.8m` (نفس بصمة الغرف الأخرى لتطابق كادر الكاميرا).

## Proposed Changes

### Component 1: مشهد React Three Fiber (`src/components/bathroom/BathroomScene.tsx`)

الحالة الحالية (آخر إصدار) تتضمن المكونات التالية:

- **`Room` — قشرة الغرفة**:
  - أرضية بلاط حجري greige كبير الحجم مع polish خفيف (`clearcoat 0.35`).
  - **جدران microcement أملس** (`roughness 0.88`) بدلاً من ألواح الحجر السابقة على الجدران الثلاثة.
  - سقف ساقط (Tray) بعمق `0.16m` وحواف `0.55m` مع شريط LED دافئ (`#ffcf88`) حول المحيط.
  - 5 سبوتات غائرة بحلقة معدنية داكنة وقرص مشع، مع مصادر `spotLight` دافئة ومنخفضة الوهج لتكوين pools ضوء واضحة على الأرضية دون تسطيح الإضاءة المحيطية.
  - وزرات حائطية (Skirting) على الجدران الخلفي والجانبيين.
- **`FlutedFeatureWall` — الجدار الخلفي**:
  - عمود مخدد ضيق (fluted pillar) بعرض `0.28m` أعيد تموضعه عند `x=-1.46` بين عمود النيش والنيش الأفقي.
  - **نيش أفقي عريض وبارز** خلف البانيو (`2.1m × 0.40m`) مع شريط LED علوي و`pointLight` دافئ و5 عناصر ديكور أسطوانية + فازة بأغصان.
- **`Vanity` — فانيتي عائمة طويلة (الجدار الأيسر)**:
  - جسم عائم بطول `3.3m` وعمق `0.56m` بواجهة مخددة عمودية (20 شريحة بلوط).
  - سطح كوارتز مصقول، و**underglow LED** دافئ أسفل الجسم.
  - **حوض vessel واحد generous** عند الطرف الأمامي + **صنبور wall-mounted** أسود بمقبض رافعة.
  - إكسسوارات: صينية حجرية بموزّعي صابون، شمعة مضيئة، فازة بأغصان يوكاليبتوس، ومنشفة مطوية.
- **`RoundMirror` — مرآة مدوّرة بإضاءة خلفية** فوق الفانيتي: هالة LED خلفية، إطار أسود رفيع، زجاج عاكس (`metalness 0.98`).
- **`Pendant` — تعليقة أسطوانية سوداء رفيعة** بجانب المرآة (بلمبة متوهجة و`pointLight`).
- **`Bathtub` — بانيو بيضاوي حر** مركزي أمام الجدار المميز:
  - قشرة خارجية مفلطحة، حافة مدوّرة، تجويف داخلي.
  - **صنبور مثبّت على الجدار (wall-mounted filler)**: escutcheon + ذراع أفقي + قوس نازل + مقبض رافعة.
  - صينية teak عرضية مع زجاجة صابون.
- **`NicheColumn` — عمود نيش طويل مُضاء (الركن الأيسر للجدار الخلفي)**:
  - وحدة بعرض `0.74m` وارتفاع `2.54m` قرب الركن (`x=LEFT_X+0.62`).
  - **5 أرفف موزّعة على كامل الارتفاع** مع شريط LED أسفل كل رف أعلى، و2–3 عناصر ديكور/فازات لكل رف، و`pointLight` دافئ.
- **`Shower` — دش زجاجي بإطارات سوداء (الركن الخلفي الأيمن)**:
  - أرضية wet-zone أغمق وقناة تصريف خطية.
  - لوح زجاجي أمامي ثابت + لوح عودة + إطارات سوداء ومقبض باب.
  - رأس مطري سقفي، وحدة تحكم + قضيب انزلاقي + دش يدوي، ونيش صغير مُضاء داخل الدش.
- **`Toilet` + `WallArt` — مرحاض معلّق ولوحة نباتية مؤطرة (الجدار الأيمن)**:
  - خزان مخفي ولوحة سيفون، كاسة، غطاء، وحامل مناديل أسود.
  - لوحة يوكاليبتوس بسيطة فوق المرحاض.
- **`Rug` — سجادة runner** مركزية بطبقتين ولمعان Sheen خفيف.
- **`FloorDecor` — فازة داكنة طويلة بأغصان** أمام يسار البانيو.
- **`Lighting`**: `ambientLight` دافئ + `directionalLight` رئيسي مُزاح لليسار لإضاءة عمود النيش + `directionalLight` fill من جهة الكاميرا + `pointLight`ين للـ bounce العام ومنطقة الفانيتي.

### Component 2: سكربت Blender المُطابق (`public/bathroom_blender.py`) [NEW]

سكربت بايثون شامل يعيد بناء كل مكونات المشهد أعلاه في Blender بدقة، مع:
- **تحويل إحداثيات** Three.js → Blender: `T(x,y,z)=(x,z,y)` و`TS(w,h,d)=(w,d,h)`، ومغلّفات `tbox`/`tcyl` لإبقاء الكود قريباً من الـ TSX.
- **مكتبة خامات** كاملة (`pbr`, `procedural_wood`, `procedural_stone`, `add_micro_bump`) مطابقة للوحة الألوان `C` في المشهد عبر المساعد `hx()`.
- **دوال بناء** لكل مكوّن: `build_room`, `build_feature_wall`, `build_vanity`, `build_mirror`, `build_pendant`, `build_bathtub`, `build_niche_column`, `build_shower`, `build_toilet`, `build_wall_art`, `build_rug`, `build_floor_decor`.
- **إضاءة** بـ `SUN` رئيسي وfill + نقاط bounce + خمس وحدات `Ceiling_Spot_0..4` دافئة وموجهة رأسيًا، وكاميرا بقيد `TRACK_TO` تطابق كادر `App.tsx` (`pos=[-0.5,1.65,7.2]`, `target=[-0.15,1.0,-0.6]`, `fov=44`).
- **إعدادات رندر**: Cycles + GPU + AgX + OpenImageDenoise + 512 عينة، مخرج `//bathroom_render.png`.

### Component 3: ربط التطبيق (`src/App.tsx`)

- تبويب الحمام مربوط مسبقاً: `script: "/bathroom_blender.py"`, `target:[-0.15,1.0,-0.6]`, `camera:[-0.5,1.65,7.2]`, `fov:44`، وزر **Download .py** ينزّل `bathroom_blender.py` الجديد من `public/`.
